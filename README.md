# Omkar Jadhav Portfolio

Premium personal developer portfolio for Omkar Pandurang Jadhav, built with Next.js 15, TypeScript, Tailwind CSS v4, Framer Motion, GSAP, React Three Fiber, Zustand, React Hook Form, Zod, Resend, and Vercel Analytics.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

If the browser shows `__webpack_modules__[moduleId] is not a function`, stop old Node servers, clear Next's dev cache, and restart with Turbopack:

```powershell
Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm run dev
```

Then hard-refresh the browser with `Ctrl+Shift+R`.

## Personalization

- Core resume-backed content lives in `src/data/profile.ts`.
- Site metadata lives in `src/config/site.ts`.
- Resume download file lives at `public/resume/omkar-jadhav-resume.pdf`.
- GitHub URL was not present in the resume, so GitHub widgets are intentionally configurable through `NEXT_PUBLIC_GITHUB_USERNAME` and `NEXT_PUBLIC_GITHUB_URL`.

## Environment

Copy `.env.example` to `.env.local` and set:

```bash
NEXT_PUBLIC_SITE_URL=https://your-vercel-domain.vercel.app
NEXT_PUBLIC_GITHUB_USERNAME=your-github-username
NEXT_PUBLIC_GITHUB_URL=https://github.com/your-github-username
NEXT_PUBLIC_TECH_STACK=Java,Spring Boot,Microservices,Docker,MongoDB,PostgreSQL
RESEND_API_KEY=re_...
CONTACT_TO_EMAIL=omkarj.9900@gmail.com
CONTACT_FROM_EMAIL=Portfolio <onboarding@resend.dev>
```

The contact API returns a configuration error until Resend variables are set, which prevents fake success states.

## SEO Guide

- Metadata is generated in `app/layout.tsx`.
- Canonical URLs use `NEXT_PUBLIC_SITE_URL`.
- Open Graph image is generated by `app/opengraph-image.tsx`.
- Twitter image reuses the Open Graph renderer in `app/twitter-image.tsx`.
- Structured data is rendered by `src/components/seo/structured-data.tsx`.
- `app/robots.ts`, `app/sitemap.ts`, and `app/manifest.ts` are production-ready for Vercel.

## Performance Guide

- Server Components are used for the page shell and metadata.
- Heavy 3D visuals are dynamically imported with SSR disabled.
- Motion effects honor `prefers-reduced-motion`.
- Resume PDF is served statically from `public`.
- Fonts use `next/font` for optimization.
- Contact email code runs only in the API route.
- Vercel Analytics is loaded through `@vercel/analytics/next`.

## Deployment

### Vercel

1. Push the repository to GitHub.
2. Import it into Vercel.
3. Set the environment variables listed above.
4. Deploy using the included `vercel.json`.
5. Run Lighthouse against the production URL and verify accessibility, SEO, best practices, and performance.

### Docker

```bash
docker build -t omkar-portfolio .
docker run --rm -p 3000:3000 --env-file .env.local omkar-portfolio
```

Open `http://localhost:3000`.

## Font

The site is configured for the Nohemi typeface. Add licensed font files at `public/fonts/Nohemi-Regular.woff2` and `public/fonts/Nohemi-SemiBold.woff2`; otherwise the browser falls back to Geist/Inter/system fonts.

## Folder Structure

```text

src/hooks/            Motion, keyboard, and UI hooks
src/lib/              Utilities, validation, and SEO helpers
```
